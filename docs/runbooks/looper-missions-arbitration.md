# Swarm Command arbitration runbook

1. Confirm the milestone is disputed and the immutable dispute deadline has not passed.
2. Review only committed artifact/evidence hashes and the signed outcome history; chat text is non-authoritative.
3. Build allocations using only predeclared milestone recipients or the immutable refund address.
4. Require per-token totals to equal the milestone liability exactly.
5. Simulate the transaction and show raw token units and recipients before the wallet prompt.
6. If arbitration is unavailable, wait for the immutable deadline; anyone may then execute only the predeclared dispute-timeout allocation.
7. Reconcile finality before issuing the signed outcome receipt or CRED evidence.
